## How to Compile and Run the Programs

Make sure Java JDK is installed on your computer.

1. Open Command Prompt inside the folder containing the Java file.
2. Compile the program:

   `javac FileName.java`

3. Run the program:

   `java ClassName`

Replace `FileName` and `ClassName` with the appropriate names.
